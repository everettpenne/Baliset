# Baliset 0.1.0

The first release: a local music player in the suite's liquid glass, with a real media session for the launcher.

**Baliset is a working name.** The package is `com.everettpenne.baliset`; if the name changes before a wider release, the package
will have to change with it, and a newly named app installs beside this one rather than over it.

## What is in it

- **Library from the phone or a folder.** Android's media index with one audio permission, or a folder you grant in the system picker
  with no storage permission. Tags and embedded cover art are read on the phone; untagged files fall back to their file name and a
  cover-shaped placeholder.
- **Background playback** through a Media3 `MediaSessionService`: media notification, lock-screen and headset controls, audio focus,
  gapless tracks, pause when headphones disconnect, and "previous" restarting the current song after three seconds.
- **Home:** jump back in where you stopped, Shuffle all / Play all, recently added albums, recently played songs and the library count.
- **Library:** albums in a grid, artists with round portraits, and every song in one alphabetical list. Album and artist pages with
  Play and Shuffle, disc-order tracks, and links between them.
- **Queue:** shuffle and repeat (off / all / one), drag to reorder, remove with ×, clear. Shuffle is the app's own order, so Up Next
  always shows what will really play.
- **Playlists and favourites**, created from anywhere with a long press on a song.
- **Search as you type** across songs, albums and artists, ignoring case and accents.
- **Now Playing:** blurred cover, draggable scrubber, the five usual controls, Up Next, a sleep timer (15 / 30 / 45 / 60 minutes or the
  end of the track), favourite, and a menu to the album or artist.
- **The launcher's island for free.** Title, artist, album, cover and duration are published on the media session, which is exactly what
  Uno Launcher reads for its island playing card, media widget and control panel. No launcher changes are needed.
- No account, no ads, no analytics and no network except the shared Glass updater's GitHub check.

## Glass

The app is built on [Glass](https://github.com/everettpenne/Glass) `v0.5.0`. That release adds the pieces this app needed and the rest
of the suite was missing: `GlassSectionHeader`, `GlassGroup`, `GlassListRow`, `GlassRowDivider`, `GlassSearchField`, `GlassEmptyState`
and the shared `GlassMiniPlayer` capsule used above the tab bar.

## What was tried, and what was not

Built and exercised on a phone-sized emulator (1080 × 2400, Android 17 / API 37) with eleven generated tracks across two albums and two
loose files:

- folder scan, tag reading, cover extraction, album and artist grouping;
- playback, the media session, the notification, shuffle, repeat, the queue, drag-to-reorder and remove;
- playlists (create, add, remove), favourites, search, the sleep timer's UI;
- light and dark themes, and the whole navigation graph.

**Not tried:**

- a physical phone, and therefore not a real GrapheneOS device;
- the system folder picker's final **Use this folder** confirmation — the emulator's automation could not activate that button. The
  picker opened and navigated correctly, and the folder scanner itself was verified through the same code path on a folder inside the
  app's storage;
- **Scan my phone** with a populated media index: the emulator's index exposed the pushed files with no tags and no `is_music`, so it
  returned nothing and the app fell back to its "choose a folder" advice. The tag-reading fallback that covers an index with missing
  tags is in the app.
- no home-screen widget yet.

## Installing

Sideload the APK. Updates are signed with the same key and install over the old app; Android asks before installing each one.
